# RAG Chat History Service

Backend microservice for storing and managing chat histories generated by RAG (Retrieval-Augmented Generated) chatbot system.

---

# Setup and running Instructions

## Prerequisites
 - Java 17
 - Maven
 - Docker
 - Docker-compose

---

## Clone repository
```bash
git clone <repository-url>
cd rag-chat-history-service
```

---

## Start Application
```bash
docker-compose up --build
```

---

# API Authentication

All APIS require the following header:
 
```http
x-api-key: your_secret_key
```

---

# Available APIs

### Chat Session APIs

- **POST** `/api/sessions`
Create a new Chat Session.
-  **GET** `/api/sessions?userId={userId}`
Retrieve all chat sessions for a user.
- **PATCH** `/api/sessions/{sessionId}/rename`
Rename an existing chat session.
- **PATCH** `/api/sessions/{sessionId}/favorite`
Mark or Unmark a session as favorite
- **DELETE** `/api/sessions/{sessionId}`
Delete a chat session and its messages.

---

### Chat Message APIs

- **POST** `/api/v1/sessions/{sessionId}/messages`  
  Add a message to a chat session.

- **GET** `/api/v1/sessions/{sessionId}/messages?page=0&size=20`  
  Retrieve paginated chat messages for a session.
